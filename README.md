# AppLogin

## Descripción

Aplicación móvil desarrollada en Android Studio con Kotlin y Jetpack Compose. Cuenta con dos pantallas: Inicio de sesión y Registro, permitiendo navegar entre ambas.

## Integrantes

* Diego Sánchez

## Ejecución

1. Abrir el proyecto en Android Studio.
2. Esperar la sincronización de Gradle.
3. Ejecutar en un emulador o dispositivo Android.
4. Comprobar la navegación entre Inicio de sesión  y Registro.
